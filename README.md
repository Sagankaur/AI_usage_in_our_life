# AI Usage in Software Engineering Project

This folder contains prepared materials for a session on using AI responsibly in the IITM Software Engineering Course project.

Recommended topic:

**AI-Augmented Software Engineering for the IITM Project: From User Research to Tested APIs and Final Review**

## What is included

- `session_preparation_checklist.md`: preparation checklist.
- `sample_repo/`: small complaint-management demo repository.
- `demo_data/`: interview notes, weak stories, acceptance criteria, and test ideas.
- `prompts/`: copy-paste prompts for each AI-assisted software engineering activity.
- `facilitator_notes/`: teaching flow, policy points, live demo checklist, and backup outputs.
- `facilitator_notes/course_alignment.md`: mapping to the May 2026 IITM project document.
- `facilitator_notes/milestone_ai_playbook.md`: how to use AI for each milestone without violating project expectations.
- `facilitator_notes/rubric_checklist.md`: checklist based on the project peer-evaluation criteria.

## Suggested session flow

1. Start with `facilitator_notes/course_alignment.md`.
2. Use `facilitator_notes/milestone_ai_playbook.md` as the student handout.
3. Continue with `facilitator_notes/teaching_flow.md`.
4. Use `demo_data/` for requirements and story-review exercises.
5. Use `prompts/` during live AI demonstrations.
6. Open `sample_repo/` for API, test, implementation, Git, and PR review demos.
7. Use `facilitator_notes/responsible_ai_policy.md` near the end of the session.
