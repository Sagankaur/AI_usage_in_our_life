# AI Usage in Software Engineering Project

This folder contains prepared materials for a session on using AI responsibly in a software engineering project.

## What is included

- `session_preparation_checklist.md`: preparation checklist.
- `sample_repo/`: small complaint-management demo repository.
- `demo_data/`: interview notes, weak stories, acceptance criteria, and test ideas.
- `prompts/`: copy-paste prompts for each AI-assisted software engineering activity.
- `facilitator_notes/`: teaching flow, policy points, live demo checklist, and backup outputs.

## Suggested session flow

1. Start with `facilitator_notes/teaching_flow.md`.
2. Use `demo_data/` for requirements and story-review exercises.
3. Use `prompts/` during live AI demonstrations.
4. Open `sample_repo/` for API, test, implementation, Git, and PR review demos.
5. Use `facilitator_notes/responsible_ai_policy.md` near the end of the session.
