# Responsible AI Policy Points

Use these points as a closing slide or discussion.

- AI output must be reviewed by the student.
- AI cannot invent user research evidence.
- AI should not receive secrets, passwords, API keys, private data, or identifiable interview recordings.
- AI-generated code must be tested.
- Students must understand every submitted line of code.
- Git history should show a clear human-reviewed workflow.
- Use free or local tools where possible.
- Prefer the smallest useful AI task over asking AI to build the whole project.
- AI can critique requirements, tests, design, and code, but it does not own engineering responsibility.
- When AI output conflicts with project requirements, project requirements win.
