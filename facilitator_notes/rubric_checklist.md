# Rubric Checklist for AI-Assisted Work

## Milestone 1

- Are primary, secondary, and tertiary users identified?
- Are interviews or observations real and evidence-backed?
- Do pain points come from user evidence?
- Are user stories SMART?
- Does each story follow the required format?

## Milestone 2

- Does the schedule come from actual user stories?
- Is a project scheduling tool shown?
- Are components described clearly?
- Are class relationships appropriate?
- Is database design connected to the workflows?
- Are scrum minutes based on real meetings?
- Do frontend screenshots cover important pages?
- Does the frontend README explain how to run the code?

## Sprint 1 and Sprint 2

- Does YAML list all required APIs?
- Is the YAML Swagger-compatible?
- Are APIs mapped to user stories?
- Are integrated APIs listed, including any GenAI APIs?
- Does implementation match YAML and user stories?
- Are validation, error handling, and responses clear?
- Are test cases in the required course format?
- Is pytest code included?
- Is pytest output included?
- Is user feedback recorded?
- Is the next sprint plan updated from feedback?

## Final Submission

- Is the complete working code included?
- Are run instructions complete?
- Are tools and technologies listed?
- Are issue tracker screenshots included?
- Are code review screenshots included?
- Are final slides and demo video ready?
- Is the final report consistent with earlier milestones?
