# Weak User Story

Use this for the story-review demo.

> As a user, I want an AI-powered dashboard with notifications so that the system is easy.

Expected discussion points:

- The user role is vague.
- The action bundles multiple features.
- "Easy" is not measurable.
- "AI-powered" is not tied to evidence.
- The story does not say what decision or task the user needs to complete.
